# 个人主页设计：怪趣档案馆

## 目标

打造一个以社交展示为主的个人主页。访客首先感受到主人外向、有趣、有生活感；“计算机研二、实习中”用于建立可信度，但不是第一视觉重点。求职和完整技术履历不在当前版本范围内，后续可独立扩展。

## 定位与语气

- 核心印象：有点混乱，但很鲜活；愿意交流，也有自己的兴趣和故事。
- 首屏主文案：`A little chaotic. Very alive.`
- 身份短文案：`计算机研二 / 实习中 / 歌房麦霸 / 剧本杀玩家`。
- 语气：直白、轻松、有一点玩笑；避免传统简历式的“技能罗列”和过度包装。

## 视觉系统

采用“怪趣档案馆”路线：私人杂志封面与个人档案卡的结合。

- 主色：薰衣草紫 `#D8D7FF`、荧光粉 `#FF477E`、奶油白 `#FFF9F0`、荧光绿 `#CAFF1B`、近黑 `#171717`。
- 字体：中文使用清晰无衬线字体；英文主标题用衬线斜体与粗体无衬线混排。
- 元素：档案框、虚线边框、贴纸、旋转标签、手写批注、不规则留白。
- 动效：首屏卡片轻微浮动；标签悬停时位移和变色；页面滚动时模块渐入。动画必须短且可降级，不能影响阅读。

## 页面结构

### 1. 首屏 Hero

导航只保留主页名、档案、现在、打招呼四个入口。主标题为 `A little chaotic. Very alive.`，左侧放一句身份与生活方式的简短介绍，右侧是一张主人照片或染发主题的视觉卡。首屏按钮引导进入“我的小宇宙”。

### 2. 我的档案

以可点击的标签卡呈现：唱歌、微醺聊天、剧本杀、染发、写代码。点击或悬停后展示一段一到两句的第一人称说明；初始内容是静态数据，后续可迁移至内容管理系统。

### 3. 最近在活

展示 3 至 6 条轻量动态：最近循环的歌、最近玩的剧本、实习中学到的新东西、一次周末记录等。每条由日期、分类、标题和一句简介组成；不做评论、点赞、登录或发布后台。

### 4. 小宇宙

首版放歌单和剧本杀角色卡两种内容。歌单可链接至外部音乐平台；角色卡显示角色名、阵营/类型、最喜欢的一句评价。朋友留言不在首版范围内，避免引入账号与审核问题。

### 5. 打招呼

以轻松的收尾文案和社交链接呈现：`想约我唱歌、喝一杯，或者聊点好玩的？来找我。` 只放主人主动提供的公开联系方式；不收集访客资料。

## 实现边界

- 首版为单页静态站点，内容从本地结构化数据读取。
- 响应式优先：手机端保持单列、卡片可点击、文字可读；桌面端展示杂志式错位布局。
- 图片使用用户授权的真实照片或抽象占位视觉；不使用未经授权的人像。
- 不包含登录、数据库、动态发布、求职简历、博客系统或在线留言。

## 验收标准

1. 首屏在手机和桌面均能在一个屏幕内看清主标题、身份和进入内容的入口。
2. 五类兴趣标签均可交互并展示对应说明。
3. 最近在活展示至少三条真实或明确标识为示例的内容。
4. 歌单外链与社交链接有明确可访问状态；没有链接时不显示空按钮。
5. 不依赖动画才能理解内容；键盘操作可访问链接和标签。

## 后续扩展

求职时新增独立的“工作模式”入口，包含研究方向、实习经历、项目与简历下载；它与当前社交主页分层，而不改写首页的性格表达。
